Obstacle Avoiding Arduino Car

Overview

This project focused on constructing an autonomous mobile vehicle capable of navigating unknown physical environments without human intervention. By deploying a real-time rangefinding system on a pivoting chassis, the vehicle constantly polls spatial depths to map its path and dynamically re-route around obstacles.

Hardware Architecture

The mechanical footprint utilizes a multi-tiered structural platform driven by dual DC motors. The computational brain consists of an ATmega328P microcontroller running customized firmware loop priorities.

To detect environmental boundaries, an HC-SR04 ultrasonic sensor is mounted to an front-facing SG90 servo motor. This enables a physical "scanning sweep" of 180 degrees whenever a forward path constraint is logged, calculating spatial vectors before firing directional motor commands.

Firmware Logic Pipeline

The software loop is engineered to maintain a fast execution lifecycle. The controller handles a state machine that switches between nominal linear movement, deceleration safety checking, distance parsing, and directional orientation corrections.

// Distance check subroutine loop void lookAround() { myservo.write(45); // Scan Right vector delay(300); distanceRight = readPing(); myservo.write(135); // Scan Left vector delay(300); distanceLeft = readPing(); myservo.write(90); // Return to center baseline }

When the front sensor registers an object closer than the configured safety threshold, the vehicle holds position, initializes a panoramic scan to compare left/right path vacancies, and prioritizes the motor spin toward the vector possessing the maximum clearance margin.
